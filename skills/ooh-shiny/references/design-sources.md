# Design source library

These are research starting points, not pre-verified examples. Availability and licensing may change. Inspect the relevant page during the task before attributing a pattern to it.

| Source | URL | Select for |
| --- | --- | --- |
| Navbar Gallery | https://www.navbar.gallery/ | Headers, menus, sticky navigation, sidebars, dropdowns, active indicators |
| Supahero | https://supahero.io/ | Hero composition, landing-page hierarchy, above-the-fold layouts |
| CTA Gallery | https://www.cta.gallery/ | Calls to action, button hierarchy, conversion sections and forms |
| Footer Design | https://www.footer.design/ | Footer navigation, closing sections, newsletter and social layouts |
| 3Dicons | https://3dicons.co/ | Optional illustrations, feature visuals, empty-state accents |
| Scrolltide | https://www.scrolltide.co/ | Scroll effects, reveals, interactive transitions and motion references |
| Refero Styles | https://styles.refero.design/ | Typography, palettes, design tokens and design-system inspiration |

Choose the smallest relevant set. For each inspected example, capture its URL, what was observable, the reusable principle, and why it fits this product. Do not assume a static screenshot demonstrates responsive behavior, keyboard access, timing, or implementation technology.

If a source is inaccessible, identify the limitation and use another accessible source or local evidence. Do not treat search snippets as inspection of the example. Do not invent example paths or claim all seven sources were reviewed.

Asset use requires checking the asset's actual license and attribution obligations. Linking to 3Dicons does not grant permission to redistribute every asset. This package includes no third-party gallery images or code.
